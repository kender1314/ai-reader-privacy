启路阅读器 隐私权政策

生效日期：2026 年 11 月 16 日　|　最后更新：2026 年 11 月 16 日

本隐私权政策适用于在 Chrome 网上应用店发布的「启路阅读器」浏览器扩展（Manifest V3） 及其相关功能。本扩展的单一用途是：帮助用户阅读、搜索、整理和朗读其主动选择的书籍、书源与章节内容。

简短说明：本扩展没有由开发者运营的账号系统或统计后端。你的书架、书源、章节缓存和设置默认保存在本机浏览器中， 不会上传给我们的服务器。只有当你主动配置书源、AI 接口或 HTTP 朗读接口时，相关内容才会按需发送给这些你指定的第三方服务。

二、我们处理的数据

“用户数据”不仅指账号信息，也包括你在使用扩展时主动提供或由扩展为你处理的内容。本扩展处理的数据如下：

1. 本地保存的数据

  • 书架信息：书名、作者、封面地址、来源地址、阅读进度等。
  • 书源配置：你添加、导入或启用的书源规则及书源元数据。
  • 章节缓存：你打开或朗读过的章节正文，用于离线继续阅读与减少重复请求。
  • 偏好设置：界面语言、主题、字号、朗读音色、语速、多角色朗读设置等。
  • 可选服务配置：你主动填写的 AI 接口地址、模型名、API Key，以及 HTTP 朗读接口模板。

上述数据通过浏览器的 chrome.storage.local 等本地存储能力保存在你的设备中， 我们不会将其上传到开发者服务器。你可以随时在扩展内清理书源、缓存或设置，也可以通过卸载扩展并清除浏览器扩展数据来删除这些数据。

2. 你配置的书源产生的数据

当你使用全网搜索、目录加载或章节阅读时，扩展会按照你启用或配置的书源规则，向对应网站发起网络请求。 这些请求可能包含你输入的搜索关键词、书名、书源地址、章节地址以及必要的请求头。

这些书源由第三方运营，不是我们的服务。对方可能在其服务器日志中看到你的 IP 地址、请求时间和请求内容， 并适用其自身的隐私权政策。我们不会集中收集这些搜索或阅读记录。

3. AI 角色识别（可选功能）

本扩展提供可选的 AI 角色识别功能，用于改善多角色朗读效果。该功能默认不启用。 只有当你主动开启、填写 OpenAI 兼容接口地址、模型名及必要的 API Key 后，扩展才会把章节文本片段、 提示词和模型配置发送给你所指定的 AI 服务提供方。

API Key 仅保存在本地，并随请求发送给你自己配置的接口，不会发送给我们的服务器。 如果你不希望文本发送至第三方 AI 服务，请关闭该功能；关闭后，扩展仍可使用本地规则进行基础角色判断。

4. HTTP 朗读接口（可选功能）

如果你主动启用 HTTP 朗读接口并配置 URL 模板，扩展会把需要朗读的文本片段编码进请求并发送给你指定的接口， 以获取语音音频。未启用时，扩展使用浏览器或操作系统提供的语音合成能力。

5. 浏览器或操作系统语音服务

当你选择浏览器或操作系统提供的在线音色时，需要朗读的文本会由相应的浏览器或平台语音服务处理。 这些服务受 Google、Microsoft 或你的操作系统供应商的隐私政策约束，不由本扩展控制。

三、我们如何使用数据

我们仅将上述数据用于实现扩展的单一用途，包括：

  • 展示和管理你的书架、书源与阅读进度；
  • 按你的指令搜索、抓取和整理你选择的书籍内容；
  • 缓存已阅读章节以提升加载速度和离线阅读体验；
  • 提供朗读、语速调节和多角色朗读；
  • 在你主动开启相关功能时，调用你配置的 AI 或 HTTP 朗读服务；
  • 排查故障、维护兼容性和保障扩展安全稳定运行。

我们不会将你的数据用于个性化广告、出售给数据经纪商、信用评估或任何与本扩展单一用途无关的目的。

四、数据共享与第三方

我们不会把你的本地数据主动共享给第三方。以下情况除外：

  • 你配置的书源：为完成你发起的搜索或阅读请求，扩展会访问对应网站。
  • 你配置的 AI 服务：仅在你开启 AI 角色识别后，发送必要的章节文本片段和配置。
  • 你配置的 HTTP 朗读接口：仅在你开启后，发送需要朗读的文本片段。
  • 浏览器/操作系统语音服务：使用在线音色时，由平台处理朗读文本。
  • 法律要求：在适用法律明确要求时，我们可能依法披露必要信息。

第三方服务的隐私实践由其各自政策约束。请在启用相关功能前自行了解并决定是否使用。

五、权限说明

storage / unlimitedStorage 用于在本地保存书架、书源、章节缓存、偏好设置和可选服务配置。
alarms 用于扩展内部的定时任务，例如本地维护任务；不用于收集浏览记录。
offscreen 用于在后台页面中实现朗读能力，尤其是浏览器 Service Worker 无法直接使用 DOM 的场景。
host_permissions（http / https） 用于访问你主动配置的书源域名、AI 接口或 HTTP 朗读接口。我们不使用该权限收集你的网页浏览历史，也不注入第三方网页。

我们遵循最小权限原则，仅申请实现上述功能所必需的权限。

六、数据保留与删除

  • 本地数据保留在你的设备上，直到你主动清理或卸载扩展。
  • 我们不为这些数据设置服务器端保留期限，因为我们不运营收集这些数据的服务器。
  • 你可以通过扩展设置清理书源、章节缓存和相关配置，也可以通过浏览器的扩展管理页面卸载扩展并清除其数据。
  • 卸载扩展不会自动删除第三方书源网站、AI 服务或语音服务在其系统中可能记录的日志；如需删除，请联系相应服务提供方。

七、数据安全

本扩展依赖 Chrome 扩展平台的本地存储隔离机制保护你的本地数据。 当使用网络功能时，建议只在可信书源和可信 AI/HTTP 接口中填写信息，并优先使用 HTTPS 地址。 我们无法控制第三方服务如何处理其接收到的数据。

八、儿童隐私

本扩展并非面向未满 13 周岁儿童（或当地法律规定年龄以下的儿童）设计， 我们不会明知地收集儿童的个人信息。如果你认为儿童向我们提供了个人信息，请通过上面的联系方式告知我们。

九、政策变更

当本扩展的功能或数据处理方式发生变化时，我们可能会更新本政策，并在此页面公布新的生效日期或更新日期。 重大变更还会通过扩展内提示或商店页面说明进行显著告知。

十、接受与联系我们

使用本扩展即表示你已阅读并理解本隐私权政策。如果你不接受本政策，请停止使用并卸载本扩展。 如需联系我们，请访问： https://gitee.com/chengdu_3/ai-reader/issues 。
